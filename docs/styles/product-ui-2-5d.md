## Prompt (copy this)

Paste into Claude, GPT or any coding model. Swap *your topic* for your own subject.

```text
Use Remotion to turn real screenshots of your product's pages into a promo video: tilt the screenshots in 3D for a 2.5D camera move, and hold key information for more than one second. Key visuals: Remotion, real page screenshots, 2.5D page camera, pages tilted then layered, beat-synced cuts, number roll-ups, flash frames, key information held for one second. Watch out: Pacing that is too fast, with the whole screen shaking on every beat, looks cheap; slow it down one notch. Output 1920×1080, 30 fps, 8 seconds, as reproducible source code rendered to MP4.
```

## Where it usually breaks · 容易失败的点

Fast pacing with the whole screen shaking together looks cheap; slow it down one notch. UI text must be real and readable, since gray blurred bars look like placeholders. A perspective angle that keeps changing causes dizziness.

节奏快、整屏一起抖会显廉价，要放慢一档；界面字要真实可读，糊成灰条就像占位图；透视角度来回变会晕。
