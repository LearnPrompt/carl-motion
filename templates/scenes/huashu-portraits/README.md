# S22–S25 卡尔特制 B（古埃及壁画／梵高厚涂／莫奈印象派／黑白橡皮管）

四支卡尔 B 共用一套 Node + Canvas 工程。S22–S24 的 A 是"少女与猫"，按上游 huashu-art-motion 的场景源码渲染；B 沿用同一套画法库（`upstream/lib`：笔触流场、调色板、绘制工具），角色换成卡尔，情节全部重写。S25 的 A 是 lemo-opuscar 的"咖啡杯追方糖"。B 按 L37 橡皮管语法新写，不引用其代码。

## 人像依据
- 依据是用户在对话中提供的本人照片：粗黑方框眼镜，黑色中分帘式刘海（垂到下颌、盖住耳朵），椭圆脸，露齿笑，米白圆领 T 恤。
- 照片只在对话里，没有存进交付包。各场景只取上述可辨识特征做风格化概括，没有描摹照片。

## 画风对齐 A 的做法
- **S22**：字形库、四色彩块边框、壁画表面（斑驳 multiply、发丝裂纹、颗粒）、阿顿小手、圣甲虫画法、铭文写出的动画，都直接取自 `upstream/02_egypt.js`（MIT）。构图改成上下两栏加河带。
- **S23 / S24**：管线和 A 相同：平涂底稿，再加分区流场笔触与区域色板。角色先平涂，再用 source-atop 补细笔触，然后补五官。S24 的笔触以 6fps 重绘（boil），节奏与 A 一致（A 每 5 帧也有一次整帧笔触跳变，见 QA）。
- **S25**：4:3 片门（1440×1080，居中，圆角，两侧黑边），灰阶，派形眼，白色四指手套，等宽面条四肢。角色逐两格（12fps），有挤压拉伸和预备动作。字幕卡为深底板加双线框，字体用 Bodoni 72 Smallcaps 代替 IM Fell SC。胶片效果按帧走：抖动、闪烁、划痕、灰尘、颗粒、暗角。同一厨房体系（菱形纹壁纸、瓷砖墙、台面、橱柜），道具换成挂钟、糖罐、盐瓶。

## 工具链与复现
- 依赖：Node ≥ 20，`npm install`（@napi-rs/canvas 0.1.65），系统 ffmpeg。S25 字幕和糖罐标签用 macOS 系统字体 Bodoni 72 Smallcaps；换机缺这款字体时会回退到默认衬线体。
- 整片：`./render_one.sh <场景> <编号>`。它会渲染 240 帧到 `../../../work/frames/<编号>`，再调 `../../pipeline/encode.sh` 编码到 `../../../out/<编号>_B_8s.mp4`。
  ```bash
  ./render_one.sh s22_egypt S22
  ./render_one.sh s23_wheat S23
  ./render_one.sh s24_bridge S24
  ./render_one.sh s25_hose  S25
  ```
- 关键帧预览：`./keys.sh <场景> /tmp/keys.jpg`，输出 0.5/2/4/6/7.5 s 拼图；单帧用 `node render.cjs <场景> <目录> 15,120`。
- 每帧都是 t 的纯函数，随机数用固定种子，重复渲染结果一致。
- 文件：`env.cjs` 在 Node 里搭浏览器全局并加载上游库；`carl_rig.js` 是 S23/S24 用的卡尔 3/4 侧绑定（走路循环、IK 手臂、刘海、眼镜、露齿笑）；`scenes/*.js` 是四个场景。S22 和 S25 的卡尔造型写在各自的场景文件里：S22 是埃及程式，S25 是橡皮管造型。

## 素材来源与许可
- `upstream/lib/*.js`、`upstream/02_egypt.js` 等来自 huashu-art-motion（MIT，见 `upstream/LICENSE_huashu`）。S22 直接复用的部分在文件头注明；S23/S24 只用了库，场景代码为新写。
- S25 依据 lemo-opuscar `styles/rubber-hose/STYLE.md` 的风格语法（MIT，见交接包 `许可与来源/LICENSE_lemo.md`），没有使用其代码或画面。
- 没有用到外部图片、贴图或音频。没有 Clawd、Huashu、少女与猫或其他现成 IP 的造型；S22 的猫只借鉴了画法。

## 模型声明
四支均由本轮 Claude Opus 5.5 编写场景源码并渲染。上游提示语和原 A 片中的模型声明属于原作，与本轮无关。

## 已知限制
- 卡尔的长相是从一张照片概括出来的风格化形象，没有经过本人确认。
- S22 的埃及程式下，卡尔改穿白亚麻褶裙（照片里是长裤），只保留了 T 恤、发型、眼镜和笑容。
- S24 中卡尔的衣服是高调平涂加细笔触，笔触密度比背景低；树影光斑做得很淡，以免读成脏污。
- S25 的角色逐两格更新，在 30fps 输出里是 3/2 帧交替保持。转向那一跳中，杯子掠过卡尔头顶时离头发很近（这是"差一点抓到"的笑点）。
